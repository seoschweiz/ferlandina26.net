Expositions: une expérience pensée pour les personnes

Une exposition transforme l’espace et propose une nouvelle façon de regarder. Dans le Raval, les œuvres, les artistes et les visiteurs peuvent dialoguer.

Préparer votre projet

Présentez le concept, les formats, le parcours, les textes et les besoins de montage.

Chaque activité est étudiée selon son contenu et les personnes qui y participeront. Indiquez la date souhaitée, les horaires, le nombre approximatif de participants et les besoins techniques.
